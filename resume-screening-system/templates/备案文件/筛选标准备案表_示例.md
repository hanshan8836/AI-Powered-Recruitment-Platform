## 第二部分：筛选标准

### 2.1 硬性门槛（不符合直接淘汰）

| 项目 | 要求 | 是否必须 |
|------|------|:--------:|
| 学历 | 本科及以上 | 是 |
| 专业 | 人力资源/心理学/管理学优先，其他专业需有2年以上HR经验 | 否 |
| 工作年限 | 2年及以上HR相关经验 | 是 |
| 必备技能 | 有招聘模块实操经验 | 是 |
| 必备证书 | 无硬性要求 | 否 |
| 其他 | 无 | 否 |

### 2.2 核心能力要求（必须具备）

**能力1：招聘实操能力**
- 能力名称：招聘实操能力
- 具体要求：熟悉招聘全流程，能独立完成JD撰写、简历筛选、面试安排、Offer谈判
- 评估方式：从简历中的工作经历和项目经验评估

**能力2：AI工具应用能力**
- 能力名称：AI工具应用能力
- 具体要求：了解并能使用AI工具辅助招聘工作（如用AI优化JD、初筛简历、设计面试问题）
- 评估方式：从简历中提及的工具使用经验评估

**能力3：沟通协调能力**
- 能力名称：沟通协调能力
- 具体要求：能与业务部门有效沟通，理解招聘需求；能提供良好的候选人体验
- 评估方式：从简历中的跨部门协作经验评估

**能力4：数据分析能力**
- 能力名称：数据分析能力
- 具体要求：能进行招聘数据统计和分析，会用Excel处理数据
- 评估方式：从简历中提及的数据相关工作评估

### 2.3 加分项（优先考虑）

1. 有AI工具深度使用经验（ChatGPT/Claude等），并有实际应用案例
2. 熟悉人才测评工具（MBTI/DISC/北森等）
3. 持有人力资源管理师证书（三级及以上）
4. 有猎头或RPO经验
5. 有大厂（BAT/TMD等）HR工作经验
