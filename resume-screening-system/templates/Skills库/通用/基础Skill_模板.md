# AI 简历筛选 Skill - 基础模板

> **重要说明**：这是创建新 Skill 的基础模板。**请务必根据公司特点和岗位需求定制此模板，不要直接使用**。参阅 [Skills 设计指南](../../../docs/Skills设计指南.md) 了解如何设计适合你公司的 Skills。

---

## 关于 Skills 和 Prompts

在使用此模板前，请理解 Skills 和 Prompts 的区别：

| 概念 | 本质 | 类比 |
|------|------|------|
| **Skill** | 封装好的能力模块 | 员工的专业技能证书 |
| **Prompt** | 单次执行的指令 | "请帮我做XX"这句话 |

**本文件是一个 Skill 定义**，它包含：
- 筛选标准（评什么）
- 评分规则（怎么打分）
- 评估流程（怎么做）
- 输出规范（输出什么格式）
- 质量保障（如何确保一致性）

当你使用时，将 Skill 内容 + 简历内容组合发送给 Claude，这才形成一个完整的 Prompt。

## 定制提醒

在填写此模板前，请先完成以下思考：

### 1. 公司画像
- 公司属于什么类型？（互联网/金融/传统企业/创业公司）
- 公司文化关键词是什么？（创新/稳健/狼性/工程师文化）
- 业务有什么特殊要求？（高并发/高安全/AI驱动）

### 2. 岗位定位
- 这个岗位解决什么问题？创造什么价值？
- 需要什么核心能力？
- 与团队现有人员如何互补？

### 3. 权重设计
- 什么能力最重要？（应该权重最高）
- 什么是加分项而非必须？（权重可以低一些）

**如果你没有思考过以上问题，请先阅读 [Skills 设计指南](../../../docs/Skills设计指南.md)**

【评分标准】
每个维度按1-5分评分，必须有具体、可衡量的定义：

- 4分 = [具体描述]
- 3分 = [具体描述]

[维度2]（权重 X%）：
- 5分 = [具体描述]
- 4分 = [具体描述]
- 3分 = [具体描述]
- 2分 = [具体描述]
- 1分 = [具体描述]

（依此类推，每个维度都需要详细的评分标准）

【分档标准】
- S档（4.5-5.0分）：优秀候选人，优先安排面试
- A档（3.5-4.4分）：良好候选人，正常安排面试
- B档（2.5-3.4分）：一般候选人，视情况安排
- C档（1.5-2.4分）：较弱候选人，暂缓安排
- 淘汰（<1.5分或未过门槛）：不安排面试

================================================================
第三部分：评估流程
================================================================

请按以下步骤评估简历：

1. 【门槛检查】
   - 逐项检查硬性门槛
   - 任何一项不符合，直接标记为"淘汰"
   - 记录淘汰原因

2. 【维度评分】
   - 对通过门槛的简历，按各维度评分
   - 每个评分必须引用简历原文作为依据
   - 严格按照评分标准打分，不要凭感觉
   - 计算加权总分

3. 【亮点识别】
   - 识别候选人的突出优势
   - 特别标记符合加分项的内容
   - 引用简历原文说明

4. 【疑点标记】
   - 标记需要进一步核实的信息
   - 标记简历中的不一致或可疑之处
   - 注意：疑点≠造假，只是需要确认

5. 【全网核实】（如启用）
   - 对学历、公司、证书进行搜索核实
   - 遵循"宁缺勿滥"原则
   - 搜到明确匹配才采用，否则标记"无法核实"
   - 搜不到不等于造假

## 使用方法

### 第一步：定制 Skill

1. 阅读 [Skills 设计指南](../../../docs/Skills设计指南.md)
2. 完成公司画像和岗位定位分析
3. 复制此模板
4. 根据分析结果填写所有 `[待填写]` 部分
5. 重点设计评分维度和权重
6. 详细定义每个分数的标准

### 第二步：备案审批

1. 将完成的 Skill 保存为独立文件（如 `Java工程师_Skill.md`）
2. 在备案表中记录 Skill 文件名和版本号
3. 提交审批
4. 审批通过后，Skill 不可修改

### 第三步：执行评估

1. 启动 Claude Code
2. 发送 Skill 内容 + 简历内容给 Claude
3. 获取标准化评估结果

## 常见问题

### Q: 为什么不能直接使用这个模板？

A: 这只是一个框架模板，没有填写任何具体标准。每个公司的需求不同，直接使用会导致：
- 筛选结果与实际需求不匹配
- 权重分配不合理
- 评分标准模糊

### Q: 如何确定评分维度的权重？

A: 权重应该反映"这个能力对岗位成功的重要性"：
- 核心能力：25-35%
- 重要能力：15-25%
- 加分能力：10-15%

### Q: 评分标准怎么写才算清晰？

A: 好的评分标准应该：
- 可衡量（有具体数字或描述）
- 可区分（不同分数有明显差异）
- 可引用（能从简历中找到证据）

**反例**：5分=很好，4分=好
**正例**：5分=有5年以上相关经验，主导过千万级DAU项目
