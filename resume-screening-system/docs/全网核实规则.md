# 全网核实规则详解

> 本文档详细说明全网核实的原则、方法和判定标准。

---

## 一、核心原则

### 1.1 宁缺勿滥

这是全网核实的最高原则：

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   宁缺勿滥 = 只采用100%确定的信息，不确定的一律不采用           │
│                                                                 │
│   搜不到 ≠ 造假                                                 │
│   不确定 ≠ 有问题                                               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 为什么要坚持这个原则？

| 原因 | 说明 |
|------|------|
| **公平性** | 不能因为搜索能力不同而造成不公平 |
| **准确性** | 模糊信息可能导致错误判断 |
| **合规性** | 避免对候选人造成不当伤害 |
| **可追溯** | 只采用可验证的信息 |

---

## 二、核实项目

### 2.1 应该核实什么

| 核实项目 | 核实内容 | 核实方式 |
|---------|---------|---------|
| 学历 | 学校、专业是否存在 | 学校官网、教育部认证 |
| 公司 | 公司是否真实存在 | 企查查、天眼查、官网 |
| 证书 | 证书类型是否存在 | 官方查询系统 |
| 个人信息 | LinkedIn、脉脉等 | 社交平台搜索 |
| 负面信息 | 是否有公开负面信息 | 新闻搜索 |

### 2.2 不应该核实什么

| 不核实项目 | 原因 |
|-----------|------|
| 候选人是否真的在某公司工作 | 个人信息通常无法公开查询 |
| 具体薪资、绩效 | 属于隐私信息 |
| 私人社交媒体 | 与工作能力无关 |

---

## 三、核实判定标准

### 3.1 判定表

| 搜索结果 | 判定 | 标记 | 是否采用 |
|---------|------|------|:--------:|
| 搜到官方来源，信息完全匹配 | 已核实 | ✓ 已核实 | 是 |
| 搜到可信来源，信息基本匹配 | 已核实 | ✓ 已核实 | 是 |
| 搜到信息但来源不可靠 | 无法确认 | ⚠️ 无法确认 | 否 |
| 搜到信息但不完全匹配 | 无法确认 | ⚠️ 无法确认 | 否 |
| 搜到同名但不确定是否同一个 | 无法确认 | ⚠️ 无法确认 | 否 |
| 完全搜不到任何信息 | 未找到 | — 未找到公开信息 | 否 |

### 3.2 判定示例

#### 示例1：学历核实（明确匹配）

```
简历写：华东师范大学 人力资源管理专业 本科

搜索结果：在华东师范大学官网找到该专业介绍，
         于2006年正式招生，是A类学科

判定：✓ 已核实
说明：学校官网（官方来源）确认该专业存在
```

#### 示例2：公司核实（明确匹配）

```
简历写：深圳市腾讯计算机系统有限公司

搜索结果：在企查查找到该公司，成立于1998年11月，
         注册地址深圳市南山区，法定代表人马化腾

判定：✓ 已核实
说明：企业信息查询平台确认公司存在，信息一致
```

#### 示例3：公司核实（无法确认）

```
简历写：深圳市ABC科技有限公司

搜索结果：找到"ABC科技有限公司"，但在北京，
         业务范围与简历描述不符

判定：⚠️ 无法确认
说明：名称相似但地点、业务不符，不能确认是同一家
采用：否
```

#### 示例4：个人信息（未找到）

```
简历写：候选人张三

搜索结果：未找到与候选人明确匹配的公开信息

判定：— 未找到公开信息
说明：很多人没有公开的职业信息，这是正常的
采用：否
是否扣分：否！搜不到≠造假
```

## 四、禁止事项

### 4.1 绝对禁止

| 禁止行为 | 原因 |
|---------|------|
| ❌ 因为搜不到就判定"造假" | 很多人/小公司没有网络信息 |
| ❌ 因为搜不到就扣分 | 违反公平原则 |
| ❌ 采用不确定的信息 | 可能导致错误判断 |
| ❌ 搜到同名就说"已核实" | 可能不是同一个人/公司 |
| ❌ 在报告中写"疑似造假" | 没有证据不能下此结论 |

### 4.2 正确做法

| 场景 | 错误做法 | 正确做法 |
|------|---------|---------|
| 搜不到公司信息 | "公司可能不存在，疑似造假" | "未找到公开信息，建议面试确认" |
| 搜到同名公司但不确定 | "已核实公司存在" | "搜到同名公司，但无法确认是否为同一家" |
| 无法确认候选人在某公司工作 | "无法核实，可能造假" | "公司存在已核实，个人任职信息需面试/背调确认" |

## 五、核实结果的使用

### 5.1 已核实的信息

- 可以增加对候选人的信任
- 可以在报告中标注为"已核实"
- 面试时可以减少在此方面的追问

### 5.2 无法核实的信息

- **不能**作为扣分依据
- **不能**标注为"疑似造假"
- **应该**标注为"待面试/背调确认"
- **应该**在面试时重点追问

### 5.3 未找到公开信息

- **不能**作为负面评价依据
- **应该**如实标注
- **应该**在面试或背调时确认

## 六、核实流程

### 6.1 标准流程

```
提取简历关键信息
       ↓
选择合适的搜索方式
       ↓
执行搜索
       ↓
分析搜索结果
       ↓
按判定标准判定
       ↓
记录核实结果
       ↓
明确标注采用/不采用
```

### 6.2 搜索方式建议

| 核实项目 | 推荐搜索方式 |
|---------|-------------|
| 学历 | 学校官网、教育部学信网 |
| 公司 | 企查查、天眼查、公司官网 |
| 证书 | 国家职业资格证书查询系统 |
| 个人信息 | LinkedIn、脉脉 |
| 负面信息 | 新闻搜索、裁判文书网 |

## 八、常见问题

### Q1: 搜到负面信息怎么处理？

**A**:
1. 确认是否是同一个人（不能仅凭同名）
2. 如果确认是同一人，记录但标注"需人工复核"
3. 由HR主管决定如何处理

### Q2: 候选人在小公司工作，搜不到公司信息怎么办？

**A**:
- 标注为"未找到公开信息"
- 不作为负面评价
- 建议面试时请候选人提供公司相关证明

### Q3: 证书需要编号才能核实，但简历没写编号怎么办？

**A**:
- 标注为"待验证"
- 建议在面试前要求候选人提供证书扫描件和编号
- 不因此扣分

### Q4: 核实结果可以作为筛选依据吗？

**A**:
- **已核实**的正面信息可以增加信任
- **未核实/无法核实**的信息不能作为扣分依据
- 核实主要是为了风险控制，不是为了筛选
