## 四、Step 3：归档存储

### 4.1 存储要求

| 要求 | 说明 |
|------|------|
| **完整性** | 所有相关文件必须齐全 |
| **可读性** | 文件格式应长期可读（PDF、JSON、MD等） |
| **安全性** | 候选人信息需要保密存储 |
| **可追溯** | 任何人查阅需要记录 |

### 4.2 存储位置

建议使用以下存储方案：

```
/archive/
├── 2026/
│   ├── HR/
│   │   ├── HRS/
│   │   │   └── 20260115/
│   │   │       └── [完整归档文件夹]
│   │   └── HRBP/
│   │       └── ...
│   ├── TECH/
│   │   ├── JAVA/
│   │   └── FE/
│   └── ...
└── ...
```

### 4.3 备份要求

- **本地备份**：至少保存一份本地备份
- **云端备份**：建议上传至企业云存储
- **定期检查**：每季度检查备份完整性

## 八、常见问题

### Q1: 候选人信息如何保密？

**A**:
1. 归档文件夹设置访问权限
2. 查阅需要审批和记录
3. 不对外泄露候选人个人信息

### Q2: 归档后发现评估有误怎么办？

**A**:
1. 记录发现时间和问题
2. 补充修正记录到归档文件
3. 不删除原始评估，标注已修正

### Q3: 保存期限到期后如何处理？

**A**:
1. 按规定销毁非必要保存的文件
2. 记录销毁清单
3. 永久保存文件不销毁
