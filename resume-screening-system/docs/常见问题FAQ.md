# 常见问题 FAQ

---

## 一、备案相关

### Q1: 筛选过程中可以修改标准吗？

**A: 不可以。**

备案文件一经审批，在本批次筛选结束前不得修改。这是保证公平公正的基础。

如需调整标准，必须：
1. 停止当前筛选
2. 重新提交备案
3. 重新获得审批
4. 从头开始筛选

### Q2: 不同批次招聘同一岗位，可以复用之前的备案吗？

**A: 可以参考，但需要重新审批。**

- 可以复用之前的筛选标准和提示词
- 但必须重新填写备案表
- 必须获得新的审批签字
- 生成新的备案编号

### Q3: 提示词可以在筛选过程中优化吗？

**A: 不可以。**

提示词是备案的一部分，必须与备案文件一致，且在筛选过程中保持不变。

如果发现提示词有问题：
- 小问题：继续完成本批次，下批次改进
- 重大问题：停止筛选，重新备案

## 二、评分相关

### Q4: 如果简历中某项信息缺失怎么评分？

**A: 标记为"简历未提及"，按该维度的最低分处理。**

示例：
- 简历中完全未提及AI工具使用
- AI应用能力维度评1分
- 评分依据写："简历未提及AI相关内容"

### Q5: 候选人自称"精通"某技能，但无法验证怎么处理？

**A: 基于简历描述评分，标记为"待面试确认"。**

- 如有项目案例支撑，可以按描述评分
- 如仅是罗列技能，评分应保守
- 建议在面试时重点追问

### Q6: 同一维度的评分标准有模糊地带怎么办？

**A: 就高不就低，但必须说明理由。**

示例：候选人情况介于3分和4分之间
- 评4分，并在依据中说明"虽然XXX不完全符合4分标准，但考虑到YYY，按4分评估"

## 三、核实相关

### Q7: 全网核实搜不到信息怎么办？

**A: 标记为"未找到公开信息"，不作为负面依据。**

很多人/小公司没有网络信息，这是正常的。

**正确做法：**
- 标记："— 未找到公开信息"
- 建议："建议面试/背调确认"

**禁止做法：**
- ❌ 标记："疑似造假"
- ❌ 因为搜不到而扣分

### Q8: 搜到负面信息怎么处理？

**A: 先确认是否是同一人，然后标记"需人工复核"。**

1. 确认是否同名同人（不能仅凭名字）
2. 确认信息来源是否可靠
3. 标记为"发现负面信息，需人工复核"
4. 由HR主管决定如何处理

### Q9: 候选人声称有证书但无法验证怎么办？

**A: 标记为"待验证"，要求提供证书编号。**

- 在报告中标记："⚠️ 待验证"
- 建议："请候选人提供证书扫描件和编号"
- 不因无法验证而扣分

## 四、公示相关

### Q10: 候选人可以查询自己的评估结果吗？

**A: 可以。**

筛选结束后，候选人可以申请查询个人评估结果，包括：
- 各维度得分及评分依据
- 档位判定
- 未通过原因（如适用）

### Q11: 公示需要公开所有候选人的名单吗？

**A: 不需要。**

公示内容包括：
- 筛选标准（公开）
- 评分权重（公开）
- AI模型信息（公开）
- 个人结果（仅限本人查询）

不公开候选人名单和排名。

### Q12: 如何处理申诉？

**A: 按照复核流程处理。**

1. 收到申诉后5个工作日内处理
2. 调出备案文件和评估报告
3. 逐项核对评分依据
4. 如有错误则修正，如无错误则说明
5. 反馈候选人

## 五、技术相关

### Q13: Claude Code如何处理PDF简历？

**A: Claude Code可以直接读取PDF文件内容。**

操作方式：
```
请读取 workspace/01_待筛选简历/候选人1.pdf 的内容并进行评估
```

### Q14: 批量筛选时中断了怎么办？

**A: 可以继续从中断的地方开始。**

操作方式：
```
请继续筛选 workspace/01_待筛选简历/ 文件夹中尚未处理的简历，
已处理的简历列表：[候选人1、候选人2、候选人3]
```

### Q15: 评估结果输出的格式有要求吗？

**A: 建议同时保存JSON和Markdown两种格式。**

- JSON格式：便于程序处理、数据统计
- Markdown格式：便于人工阅读、归档

## 六、合规相关

### Q16: 使用AI筛选简历是否合规？

**A: 关键是透明和可追溯。**

本系统的合规设计：
1. **透明性**：筛选标准、AI模型全部公示
2. **可追溯**：所有评分有依据，全程留痕
3. **可申诉**：候选人可查询结果、提出申诉
4. **人工复核**：AI筛选是初筛，最终决策由人做出

### Q17: 候选人信息如何保密？

**A: 遵循以下原则：**

1. 简历仅限招聘相关人员查看
2. 归档文件设置访问权限
3. 查阅需要审批和记录
4. 筛选结束后按规定期限保存或销毁

### Q18: 备案文件保存多久？

**A: 永久保存。**

| 文件类型 | 保存期限 |
|---------|---------|
| 备案文件 | 永久 |
| 入职候选人简历 | 永久（人事档案） |
| 未入职候选人简历 | 3年 |
| 评估报告 | 永久 |
| 审计日志 | 永久 |

## 七、特殊情况

### Q19: 如果发现明显造假的简历怎么办？

**A: 标记疑点，不直接判定，建议核实。**

1. 标记具体的可疑之处
2. 标记为"疑点"，不是"造假"
3. 建议在面试时追问
4. 必要时进行背景调查
5. 最终判定由人做出，不是AI

### Q20: 候选人简历更新了，需要重新评估吗？

**A: 视情况而定。**

- 如果筛选尚未结束：使用最新简历评估
- 如果筛选已结束：不重新评估，候选人可参加下批次招聘
- 如果候选人提出申诉并提供新信息：按申诉流程处理

### Q21: 用人部门对筛选结果不满意怎么办？

**A: 复盘筛选标准，在下批次调整。**

1. 了解用人部门的具体不满意之处
2. 分析是标准问题还是候选人质量问题
3. 如是标准问题，在下批次调整备案
4. 当前批次的结果不可修改（已备案锁定）

## 八、最佳实践

### Q22: 如何设计一个好的提示词？

**A: 遵循以下原则：**

1. **明确角色**：告诉AI它是什么角色
2. **明确标准**：硬性门槛、能力要求、加分项
3. **明确规则**：评分维度、权重、各分数标准
4. **明确输出**：JSON格式、必须包含的字段
5. **明确禁止**：核实规则、禁止事项

### Q23: 如何提高筛选的准确性？

**A: 建议以下做法：**

1. 筛选前充分与用人部门沟通
2. 评分标准尽量量化、具体
3. 每个评分都要引用简历原文
4. 人工复核S档和淘汰的简历
5. 筛选后收集用人部门反馈，持续改进

### Q24: 如何处理大量简历的批量筛选？

**A: 分批处理，做好进度管理。**

1. 将简历分成若干批次（每批10-20份）
2. 逐批发送给Claude处理
3. 每批处理完成后保存结果
4. 处理完所有批次后生成汇总表
5. 人工抽检确认质量
