# 第三阶段：筛选后【公示】详细指南

> 本指南详细说明如何完成筛选后的公示工作，确保透明公正。

---

## 一、公示流程概览

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  Step 1     │    │  Step 2     │    │  Step 3     │    │  Step 4     │
│  生成汇总表 │ →  │  准备公示   │ →  │  开放查询   │ →  │  处理申诉   │
│             │    │             │    │             │    │             │

└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

## 二、Step 1：生成结果汇总表

### 2.1 汇总表必须包含的内容

| 列名 | 说明 | 示例 |
|------|------|------|
| 排名 | 按总分排序 | 1、2、3... |
| 姓名 | 候选人姓名 | 王芳 |
| 总分 | 加权总分 | 4.90 |
| 档位 | S/A/B/C/淘汰 | S档 |
| 留下的原因 | 主要亮点 | AI应用突出、大厂背景 |
| 去掉的原因 | 疑点或淘汰原因 | 无 / 学历不符 |
| 核实状态 | 核实结果汇总 | 学历已核实，公司已核实 |
| 后续建议 | 面试/背调建议 | 追问AI实践细节 |

### 2.2 汇总表示例

| 排名 | 姓名 | 总分 | 档位 | 留下的原因 | 去掉的原因 | 核实状态 | 后续建议 |

| 1 | 王芳 | 4.90 | S | AI应用突出、双大厂背景、有量化成果 | 无 | 学历✓ 公司✓ | 追问AI实践 |
| 2 | 李明 | 4.00 | A | 有证书、校招经验 | AI描述较少 | 学历✓ | 考察AI能力 |

### 2.3 汇总表文件格式

建议使用两种格式保存：

1. **Excel格式**（.xlsx）：便于筛选、排序、统计
2. **Markdown格式**（.md）：便于归档和公示

## 五、Step 4：处理申诉

### 5.1 申诉处理流程

```
收到申诉 → 调取资料 → 复核评估 → 判定结果 → 反馈候选人
    ↓          ↓          ↓          ↓           ↓
  记录编号   备案表+      逐项核对    有错则改    5工作日内
            评估报告     评分依据    无错说明
```

### 5.2 申诉复核要点

复核时需要检查：

1. **门槛判定是否正确**：简历信息是否满足门槛要求
2. **评分依据是否正确**：引用的简历内容是否准确
3. **评分标准是否一致**：是否按照公示的标准评分
4. **计算是否正确**：加权总分计算是否有误

### 5.3 申诉结果处理

| 复核结果 | 处理方式 |
|---------|---------|
| 评估无误 | 向候选人说明评估依据和过程 |
| 评分有误 | 修正评分，重新计算，更新档位 |
| 门槛判定有误 | 重新评估，如改为通过则安排后续 |
