# 第二阶段：筛选中【执行】详细指南

> 本指南详细说明如何使用Claude Code Agent执行简历筛选。

---

## 一、执行流程概览

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  Step 1     │    │  Step 2     │    │  Step 3     │    │  Step 4     │
│  准备简历   │ →  │  启动Claude │ →  │  发送指令   │ →  │  获取结果   │
│             │    │             │    │             │    │             │
│  整理简历   │    │  启动CLI    │    │  粘贴简历   │    │  保存报告   │
│  放入文件夹 │    │  确认环境   │    │  等待评估   │    │  核实信息   │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

---

## 二、Step 1：准备简历

### 2.1 简历文件准备

将所有待筛选的简历放入指定文件夹：

```bash
workspace/01_待筛选简历/
├── 候选人1_张三.pdf
├── 候选人2_李四.pdf
├── 候选人3_王五.docx
└── ...
```

### 2.2 简历命名规范

建议使用统一的命名格式：

```
[序号]_[姓名]_[应聘岗位].[格式]

示例：
001_张三_Java工程师.pdf
002_李四_Java工程师.pdf
```

### 2.3 支持的简历格式

| 格式 | 说明 |
|------|------|
| PDF | 推荐，格式固定 |
| Word (.docx) | 支持，但可能有格式问题 |
| 纯文本 (.txt) | 支持 |
| 图片 | 需要OCR转换 |

## 四、Step 3：发送筛选指令

### 4.1 完整指令模板

```
请按照以下备案标准筛选简历。

================================================================
备案信息
================================================================

【备案编号】：[从备案表获取]
【岗位名称】：[从备案表获取]
【提示词版本】：[从备案表获取]

================================================================
筛选标准
================================================================

【硬性门槛】
[从备案表粘贴硬性门槛部分]

【核心能力要求】
[从备案表粘贴核心能力部分]

【加分项】
[从备案表粘贴加分项部分]

================================================================
评分规则
================================================================

【评分维度与权重】
[从备案表粘贴评分维度和权重]

【分档标准】
- S档（4.5-5.0分）：优秀候选人，优先安排面试
- A档（3.5-4.4分）：良好候选人，正常安排面试
- B档（2.5-3.4分）：一般候选人，视情况安排
- C档（1.5-2.4分）：较弱候选人，暂缓安排
- 淘汰（<1.5分或未过门槛）：不安排面试

================================================================
全网核实规则
================================================================

【核实原则】：宁缺勿滥，只采用100%确定的信息

【核实判定】：
- 搜到明确匹配 → ✓ 已核实
- 搜到但不确定 → ⚠️ 无法确认（不采用）
- 搜不到 → — 未找到公开信息（不作为负面依据）

【禁止事项】：
- ❌ 禁止因为搜不到就判定"造假"
- ❌ 禁止采用不确定的信息

================================================================
执行任务
================================================================

请对以下简历进行评估：

1. 门槛检查（不符合直接淘汰）
2. 五维度评分（必须引用简历原文作为依据）
3. 亮点识别
4. 疑点标记
5. 全网核实
6. 输出JSON格式的评估报告

================================================================
简历内容
================================================================

[粘贴简历内容，或指定简历文件路径]
```

### 4.2 单份简历筛选

如果是逐份筛选，可以直接粘贴简历内容：

```
请按照备案编号 BP-HR-HRS-20260115-001 的标准评估以下简历：

---简历开始---

姓名：张三
电话：138****8888
...

---简历结束---
```

### 4.3 批量简历筛选

如果需要批量筛选，可以指定文件夹：

```
请读取 workspace/01_待筛选简历/ 文件夹中的所有简历，
按照备案编号 BP-HR-HRS-20260115-001 的标准逐份评估，
并生成汇总表。
```

## 六、全网核实操作

### 6.1 核实流程

```
提取简历信息 → 搜索核实 → 判定结果 → 记录说明
      ↓              ↓           ↓          ↓
  学历/公司/证书   网络搜索   明确匹配才采用  详细记录
```

### 6.2 核实指令示例

```
请对候选人王芳的以下信息进行全网核实：

1. 学历：华东师范大学 人力资源管理专业
2. 公司：深圳市腾讯计算机系统有限公司
3. 公司：字节跳动
4. 证书：人力资源管理师三级

核实原则：
- 只采用明确匹配的信息
- 搜不到或不确定的，标记为"无法核实"
- 绝对禁止因为搜不到就判定"造假"
```

### 6.3 核实结果记录

| 核实项目 | 搜索方式 | 搜索结果 | 判定 |
|---------|---------|---------|------|
| 华东师范大学人力资源管理专业 | 学校官网 | 该专业确实存在 | ✓ 已核实 |
| 腾讯公司 | 企业信息查询 | 公司存在，与简历一致 | ✓ 已核实 |
| 候选人是否在腾讯工作 | 无法搜索 | 个人信息不可查 | — 无法核实 |
| 人力资源管理师三级 | 证书查询系统 | 需要证书编号 | ⚠️ 待验证 |

## 七、常见问题处理

### Q1: 简历是图片格式怎么办？

**A**: 使用Claude的图片识别功能，或先进行OCR转换。

### Q2: 简历信息不完整怎么评分？

**A**: 对于简历未提及的信息，标记为"简历未提及"，该维度按最低分处理或特殊标注。

### Q3: 遇到明显造假的简历怎么办？

**A**:
1. 只标记为"疑点"，不直接判定造假
2. 记录具体的疑点内容
3. 建议在面试环节重点追问
4. 必要时进行背景调查

### Q4: 批量筛选时中断了怎么办？

**A**: Claude Code可以继续从中断的地方开始，只需指定尚未处理的简历。
