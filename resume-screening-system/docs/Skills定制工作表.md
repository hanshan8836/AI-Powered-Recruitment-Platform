# Skills 定制工作表

> 按照本工作表的步骤，一步步设计适合你公司的 Skills。

---

## 使用说明

本工作表帮助你系统性地设计一个岗位的 Skill。请按顺序填写每个部分。

**建议流程：**
1. HR 与用人部门一起填写第一部分（公司画像和岗位定位）
2. HR 填写第二部分（评估维度设计）
3. 提交管理层审批
4. 审批通过后，导出为正式 Skill 文件

**根据加权总分，将候选人分为不同档位：**

| 档位 | 分数范围 | 含义 | 后续处理 |
|------|---------|------|---------|
| S档 | 4.5-5.0 | 优秀候选人 | 优先安排面试 |
| A档 | 3.5-4.4 | 良好候选人 | 正常安排面试 |

## 设计检查清单

在提交审批前，请确认以下事项：

**门槛设计检查：**
- [ ] 硬性门槛只包含真正必须的条件
- [ ] 可替代或可培养的能力没有设为门槛
- [ ] 门槛条件清晰、可验证

**维度设计检查：**
- [ ] 维度数量在 4-6 个之间
- [ ] 权重合计等于 100%
- [ ] 最重要的能力权重最高
- [ ] 每个维度都有明确的评估依据

**评分标准检查：**
- [ ] 每个分数都有具体描述
- [ ] 不同分数之间有明显区别
- [ ] 标准可衡量、可从简历中找到证据
- [ ] 没有使用模糊描述（如"很好"、"一般"）

**整体检查：**
- [ ] Skill 设计反映了公司文化和价值观
- [ ] Skill 设计针对本公司的具体需求（非通用模板）
- [ ] 用人部门确认了设计内容
- [ ] 已获得审批签字
