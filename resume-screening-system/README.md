## 系统概述

本系统基于 **Claude Code Agent** 本地化运行，为企业提供一套标准化的AI简历筛选流程。

### 为什么需要这套系统？

1. **公平公正**：所有筛选标准、提示词、评分权重必须事先备案，筛选过程中不可修改
2. **透明可查**：筛选结束后公示标准，候选人可查询个人评估结果
3. **全程留痕**：所有评估都有据可查，支持事后审计
4. **宁缺勿滥**：全网核实只采用100%确定的信息，不因搜不到就判定造假

### 适用场景

- 企业批量简历筛选
- 校园招聘简历初筛
- 社会招聘简历评估
- 内部竞聘材料评审

## 快速开始

### 前置要求

本系统基于 **Claude Code** 运行，支持两种使用方式：

#### 方式一：Claude Code App（推荐）

直接在 Claude 桌面/网页应用中使用：

1. 访问 [Claude](https://claude.ai) 并登录
2. 在对话中添加本项目文件夹，授予访问权限
3. 即可开始对话式筛选

**优点**：开箱即用，无需安装配置，图形化界面友好

#### 方式二：Claude Code CLI（命令行）

适合开发者和需要自动化的场景：

1. 已安装 [Claude Code CLI](https://docs.anthropic.com/claude-code)
2. 有效的 Claude API 访问权限
3. 本地运行环境（macOS / Linux / Windows WSL）

**优点**：可脚本化、自动化，适合批量处理

---

### 5分钟快速体验

#### 使用 Claude Code App

1. **准备简历**：将待筛选的简历文件放入 `workspace/01_待筛选简历/` 文件夹
2. **打开 Claude**：访问 [claude.ai](https://claude.ai)
3. **添加文件夹**：点击对话框中的"添加文件夹"按钮，选择本项目的 `resume-screening-system` 文件夹
4. **发送指令**：告诉 Claude 你要筛选简历，例如：
   > "请根据 templates/提示词库/技术部门/Java工程师_提示词.md 的标准，筛选 workspace/01_待筛选简历/ 中的简历"

#### 使用 Claude Code CLI

```bash
# 1. 进入系统目录
cd resume-screening-system

# 2. 将待筛选简历放入指定文件夹
cp /path/to/resumes/*.pdf workspace/01_待筛选简历/

# 3. 复制并填写备案文件
cp templates/备案文件/筛选标准备案表_模板.md workspace/我的备案.md
# 编辑 workspace/我的备案.md，填写岗位要求

# 4. 启动Claude Code，执行筛选
claude

# 5. 在Claude中发送筛选指令（参考 docs/执行指南.md）
```

## 使用指南

### 1. 如何选择/设计提示词？

**如果是常见岗位：** 直接使用 `templates/提示词库/` 中对应岗位的提示词模板

**如果是特殊岗位：** 基于 `templates/提示词库/通用/基础提示词_模板.md` 进行定制

**提示词设计原则：**
- 必须明确硬性门槛（不符合直接淘汰）
- 必须明确评分维度和权重（加起来=100%）
- 必须明确评分标准（1-5分各代表什么）
- 必须明确输出格式（JSON或Markdown）

### 2. 如何进行全网核实？

**核实原则：宁缺勿滥**

| 搜索结果 | 判定 | 标记 |
|---------|------|------|
| 搜到官方来源，信息完全匹配 | 采用 | ✓ 已核实 |
| 搜到信息但不完全确定 | 不采用 | ⚠️ 无法确认 |
| 完全搜不到 | 不采用 | — 未找到公开信息 |

**禁止事项：**
- ❌ 禁止因为搜不到就判定"造假"
- ❌ 禁止采用不确定的信息
- ❌ 禁止用模糊结果给候选人扣分

### 3. 如何处理申诉？

1. 候选人提交申诉
2. HR调出评估报告和备案文件
3. 核对评分依据是否正确
4. 如有错误，修正并记录
5. 5个工作日内反馈结果

## 常见问题

### Q: 筛选过程中可以修改标准吗？

**A: 不可以。** 备案文件一经审批，在本批次筛选结束前不得修改。如需调整，必须：
1. 停止当前筛选
2. 重新提交备案
3. 重新审批
4. 从头开始筛选

### Q: 全网核实搜不到信息怎么办？

**A: 标记为"未找到公开信息"，不作为负面依据。** 很多小公司或普通员工没有网络信息，搜不到≠造假。建议在后续面试或背调环节确认。

### Q: 如何保证AI评估的一致性？

**A: 通过以下措施保证：**
1. 使用相同的提示词（备案锁定）
2. 使用相同的模型版本（备案记录）
3. 所有评分必须引用简历原文作为依据

### Q: 候选人可以查询自己的评估结果吗？

**A: 可以。** 筛选结束后，候选人可以申请查询个人评估结果，包括：
- 各维度得分及依据
- 档位判定
- 未通过原因（如适用）
